# 短剧 UI 原稿与当前实现复核

设计依据为飞书[短剧设计](https://zv7w2qqgbu9.feishu.cn/wiki/B58PwmcStiu0UZkKKs6ccZWZnQg)第 129 版的 40 张参考图。图号按原文图片顺序编号，图片标识及顺序与已缓存参考一致。前轮复核以仓库 `644bb3a0` 基础上的工作区为依据；最新段导航调整另行记录验证结果。

本轮重点是修正真实页面与原图之间的布局、比例及操作位置差异，并核对操作是否使用现有业务能力。新建六步、单集五步和作品管理四标签保持原稿名称、顺序与页面归属。页面设计及业务合同见[流程与功能设计](short-drama-workflow-v2.md)。本文记录当前实现与范围边界，不将源码修改或专项通过表述为整套视觉验收完成。

最新交互决策取消“幕”，恢复“集 → 段 → 镜头”：左侧选择真实剧情段，右侧展示该段镜头；场景仅保留在镜头信息中。生成批次、失败重试和视频预览按段操作，单镜生成保留在媒体工作区。本次调整已通过专项、前端构建和 lint，真实浏览器仍待验收；前轮幕布局及其操作记录保留为历史，不作为新行为的视觉验收证明。

## 保留的业务合同

- 创作层级为集 → 段 → 镜头，段使用真实剧情段及镜头关联，不由相邻场景重分组。批量生成、失败重试和预览明确段范围；镜头媒体工作区保留单镜操作，原“跨幕关联段”说明退为历史。
- 正文与设置使用 CAS。创建按“保存正文与范围 → 使用返回版本保存制作设置 → 更新名称和备注”提交；部分成功保留最新版本供重试。单集章节关联为空或查询失败时阻断，不回退全剧正文。保存正文不隐式重新生成媒体。
- 原文导入与加入制作分开表达；默认先选首章且允许手动调整。确认后的预留章通过共用章节选择器追加，使用真实章 ID 和修订号，已有集保留；查看、勾选和提交分别操作，不自动选择或加入。
- 新建分集固定打开时的修订号，版本变化或结果不确定时保留输入并阻断重发；提交中禁止关闭，有草稿时确认放弃。连续文件只采用最后选择，人工输入使旧读取失效；末尾追加与前后插入各自沿用服务端阶段门禁。
- 默认分镜模式确认仍在 `assets → story`，只写该页拥有的模式、导演模板、镜数、模型和规格，保留小说分组与其他设置。缺少首帧或参考图时要求补图，不静默改成文生视频。
- 无逐镜视频采用时按剧情段合成；任一镜头存在当前采用指针时，整集使用全部镜头的有效采用视频。缺镜、脚本过期、采用不一致、资源或时长无效会阻断，不混用旧段视频。
- 素材包包含所选集已采用的镜头图片、视频和音频；当前脚本提示词与采用版本提示词分别记录，未采用历史不入包，损坏采用拒绝导出。剪映仍使用剧情段视频。
- 当前批次显示会话内逐项结果。服务端已有批量预检、防重和镜头操作回放继续使用，不从页面回执限制推断重复计费。
- 画布入口只创建画布并传递本次待发 Agent 草稿。技能与参考图随待发输入在新画布恢复；创建、跳转和恢复本身不启动模型或收费生成。该接续使用通用 Canvas Agent，不重新启用已退役的专用短剧聊天或扩大短剧编辑稿的通用持久恢复范围。

前端实现主要位于 `web/src/pages/projects/`；合成、导出、阶段确认及批量合同位于 `backend/internal/app/`。具体页面映射见[流程与功能设计](short-drama-workflow-v2.md)。

## 本轮范围与行为边界

试稿书单、授权书单、我的小说/小说库服务、转绘出海、独立“匹配全部主体”批量功能均明确排除，不列作本轮后续补齐项。原图中这些内容只用于说明参考与当前范围的差别。

独立音频混音、逐镜剪映时间线、未保存编辑草稿的持久恢复、统一持久批次回执与跨登录恢复没有获得本轮实现授权。当前声音、导出、任务与会话保护的实际边界已在对应页面说明；它们也不是本轮 TODO。完整派生版本关系、统一任务定位和结构化场景/道具库不因已有局部接口而被宣称完整可用。当前没有新增这些服务的承诺。

## 设计规则采用范围

使用 ui-ux-pro-max 的 Web 导航、步骤进度、错误恢复、焦点及异步反馈建议，结合[仓库组件规范](../plans/ui-design-system.mdx)、三层 token、既有 Lucide 图标和主题。进度、可聚焦错误反馈及异步错误处理用于完善当前页面，不替代已有 TanStack Query 和 API 合同。桌面 Web 制作工具不直接套用原生 App 的底部导航、触感或 pt/dp 规范。
