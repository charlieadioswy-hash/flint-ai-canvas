依据为[短剧设计](https://zv7w2qqgbu9.feishu.cn/wiki/B58PwmcStiu0UZkKKs6ccZWZnQg)第 129 版的 40 张参考图。本文记录本轮真实页面的视觉修正及现有功能合同；逐图对应见[设计复核](short-drama-ui-recheck.md)，上一轮实施记录见[重构实施计划](short-drama-workflow-rebuild.md)。

剧本与剧集路径已在隔离真实后端 8082、前端 3002 和新测试账号下走通来源选择、剧本保存、阅读、创建弹窗、风格设置及作品管理的分集管理、主体资产路径。最新三页签等高区域已在真实浏览器反复切换验证：桌面、窄屏及明暗主题下，同宽的最近作品标题位置完全一致；唯一主上传入口、桌面创意弹窗关闭/重开保稿及手机竖屏/横屏弹窗均已核对，运行/采用确认分支待验。此前不同页签坐标已标为历史。通用画布的快捷提示词与上传参考图已走通过新画布独立 Agent 的待发恢复，技能携带由真实组件专项覆盖，浏览器只验技能空态。画布提示云端对话未同步、本机草稿已保留，不据此认定云端对话同步或 Agent 运行通过。隔离测试账号任务数为 0，未发起供应商生成；有内容的资产编辑、模式、分镜媒体与成片页仍待真实数据下的浏览器验收，最终记录集中在[待测试清单](../content/docs/progress/pending-test.mdx)。

## 流程与导航

新建创作严格保留原稿六步：

```mermaid
flowchart LR
    A[上传剧本] --> B[剧本格式]
    B --> C[风格设置]
    C --> D[角色场景]
    D --> E[漫剧分镜]
    E --> F[视频预览]
```

单集创作保留 **分集剧本 → 风格设置 → 角色场景 → 漫剧分镜 → 视频预览**。作品管理保留 **剧本设定 / 风格设置 / 主体资产 / 分集管理**。新建与单集的导航分别存在；管理标签用于管理作品，不能替换为创作步骤。

| 环节                | 页面职责                                                           |
| ------------------- | ------------------------------------------------------------------ |
| 上传剧本            | 选择来源，上传或粘贴，显示就绪状态与格式参考                       |
| 剧本格式 / 分集剧本 | 默认阅读分集正文，显式手动编辑，下载及创建                         |
| 风格设置            | 选择真实绘图模型、角色/场景模板、风格及参考样图                    |
| 角色场景 / 主体资产 | 提取、导入、新增及编辑角色、场景、道具，管理形象、声音、视图和版本 |
| 漫剧分镜            | 选择默认模式，按幕管理镜头，在镜头内完成图片/视频/音频操作         |
| 视频预览            | 预览、合成和下载实际采用视频，显示真实就绪或阻断原因               |

图片、视频、音频是镜头媒体标签；角色、场景、道具是资产分类，均不升为新阶段。原稿未要求的审阅、装配或独立视频制作不新增为必经流程。

## 创作入口与来源选择

`DramaWorkflowEntry` 提供“剧本 / 剧集 / 画布”三个页签。剧本与剧集共用当前正文、文件和创意会话；切换保留输入。剧集页只显示精品漫、真人剧、漫剧解说三张真实类型卡，分别保存 `dramaType=comic/live_action/narration`，转绘出海卡已移除。

入口采用紧凑布局，三页签居中紧邻，总宽 240px、高 36px。入口区最大宽 920px，左右内边距 16px，上下内边距分别为 28px 和 24px，内部间距 16px。三个面板叠放在同一 CSS Grid 区域，非当前面板以 `visibility` 隐藏并设为 `inert`、`aria-hidden`，继续参与最大自然高度计算；共用区域 `min-block-size: 280px`，内容可自然撑高，不裁剪、不增加内滚动。因此切换页签时，下方“最近作品”保持位置。入口上方不重复放短剧大页头，作品标题与浏览工具集中到下方“最近作品”。真实浏览器反复切换三页签后，同宽标题 Y 完全相等：1440×900 为 540.92px，1024×768 为 535.72px，390px、375px 宽均为 768.45px；1440px 明暗主题下仍为 540.92px。共用区域实测桌面高 300.53px、手机高 553.27px。

点击类型后打开“选择创作方式”弹窗，纵向列出“从小说开始 / 从剧本开始 / 从分镜开始”。选择后进入上传或粘贴区域，右侧展示对应格式参考；隐藏作品列表、列表标题和搜索，顶部始终显示六步导航，返回恢复类型卡和列表。类型卡、来源弹窗和上传页是依次发生的交互，来源不再作为入口内横向单选组。

保存 `dramaType` 不自动改变风格筛选和供应商生成规则。当前入口支持直接文件、输入和已有作品接续；试稿书单、授权书单、我的小说及小说库服务、转绘出海明确排除，没有保留为本轮补齐任务。

画布页签按原图采用左右布局：左侧为点阵背景的“新建画布”卡，右侧复用通用 Canvas Agent composer，提供想法输入、技能选择及参考图入口，下方保留四项快捷入口。快捷入口仅预填提示词，用户仍可修改，不直接调用生成。

点击新建卡创建空画布；从 composer 继续则创建画布，并在进入新画布后恢复本次待发提示词、技能与参考图。恢复只准备输入，由用户检查后明确发送，创建、跳转或恢复均不自动启动模型、提交付费生成或恢复已退役的专用短剧 Agent。创建及跳转失败保留输入，提交中防止重复创建；账号切换或晚到响应不得把草稿交给其他账号或画布。

前往新画布前仍处理未保存正文或未采用创意；取消后保留来源、类型和稿件。文件读取、创意运行和创建提交中冻结入口切换。这次画布间待发输入接续不扩大短剧正文、资产等编辑稿的通用持久恢复范围。

创作入口下方首先展示“最近作品”标题及搜索、状态筛选，旁侧不再重复提供上传/粘贴操作，对应隐藏文件输入也已移除。卡片采用左侧 80px 方形缩略图、右侧正文的横向结构，整组使用 `auto-fill`、最小列宽 300px 的响应式网格，720px 以下单列；不使用局部横向滚动列表，窄屏不得撑宽整页。作品信息与打开或继续路径来自真实列表，查询、状态和删除等业务合同保持。进入上传视图后继续隐藏最近作品、搜索与列表标题，返回恢复。

历史测量：上一版在 1440×900 下，画布页标题/卡片起点为 y=452/576px，剧集页为 y=380/504px，剧本页为 y=549/673px，画布区内容高 166px。最新共用等高布局已替代这些随页签变化的位置，旧截图不作为当前固定位置通过证明。

## 上传剧本

页面以大面积居中的虚线上传区作为唯一主上传入口，右上提供“手动输入/粘贴”，进入手动模式后原位置改为“改为上传文件”，切换保留本会话输入。文件就绪后，在上传区内展示文件名、作品名、章节数量、就绪标识和替换入口。右侧窄格式参考分别说明单集与场次结构，小说来源显示相应章节格式。

沿用 TXT、MD、Markdown、DOCX 真实读取，文件上限 30 MB；旧 DOC 提示先转换。解析后显示实际章节与默认制作范围，显式保存才替换正文。读取、解析或保存失败保留输入并说明原因；该操作不调用媒体生成模型。

上传完成后进入独立的剧本格式页，后续配置不堆叠在上传区内。

## 创意扩写弹窗

“一句想法生成正文”使用 `AppModal` 呈现，`destroyOnHidden=false` 保留当前页面会话，关闭不销毁想法、生成结果和采用状态。没有草稿时直接关闭；有未采用修改时，在同一弹窗中选择“继续创意扩写”或“保留草稿并关闭”。运行中或采用确认中禁止关闭，采用正文前的确认也在当前弹窗内完成，不另叠独立确认弹窗。保留草稿仍限当前会话，不承诺刷新或跨登录恢复。

弹窗只改变入口呈现，扩写模型、输出形式、历史及显式采用沿用既有合同；采用后回到原剧本流程，不增加创作阶段。

桌面真实页面已确认弹窗为 `dialog`，页面不再内联展示 `WorkflowIdea`；打开/关闭时最近作品标题均保持 y=540.92px。输入想法后按 Esc，经过关闭确认并选择“保留草稿并关闭”，再次打开原文保留。390×844 下弹窗宽 374px，位于 x=8–382px，控件最大宽 326px；844×390 下弹窗宽 812px，位于 x=16–828px，正文区域高 230px。两种方向正文与整页均无横向溢出，保留同一想法。运行/采用确认分支仍待验，未发起收费扩写任务。

## 剧本格式与分集剧本

按原图使用紧凑分集目录与正文阅读区，不在目录和正文外增加独立卡片壳。默认显示排版正文；点击“手动编辑”才出现标题和正文表单。保存、取消和放弃分别处理当前编辑状态，切集保留本次会话草稿。下载包含当前范围内全部章节及当前编辑稿；离开有修改保护，不承诺刷新或重新登录恢复未保存稿。

创建剧集/单集使用 620px 单列弹窗，顺序为名称、三张图片类型卡、当前来源摘要、画幅、备注，提交按钮为“新建”。画幅顺序为 16:9、4:3、1:1、9:16、3:4，均使用真实后端合同，不呈现 21:9。制作范围和来源类型默认收起，在调整范围时展示逐章选择。

“创建剧集”使用勾选章节，“创建单集”使用当前章节，操作更新当前作品，不克隆另一个项目。当前来源摘要不是任意跨项目剧本选择器。提交按“保存正文与范围 → 使用返回版本保存制作设置 → 更新作品名称与备注”顺序执行，每次成功保留最新版本；后续失败保留表单和已保存结果供重试，防止重复提交。完成后进入风格设置。

当前简易入口默认一章一集。详细创建中的小说固定合章和 AI 自动分集继续使用原合同，弹窗不重置旧项目的分组规则。单集路由读取真实 `chapterIdsJson`，只展示、编辑和下载关联章节；关联为空或读取失败时阻断，不回退全剧正文。编辑会话按账号、作品和单集隔离，晚到响应不能覆盖其他会话。

正文保存与重新改编分别执行。保存不隐式重生媒体；重新改编显示真实影响范围并保留现有结果，不以完整派生版本关系已实现来描述当前局部保护。

## 风格设置

保留左侧配置、右侧预览：左侧包括绘图模型、角色绘图模板、场景绘图模板、预设/自定义风格和分类；右侧展示选中风格样图，可放大查看。样图来自真实风格封面和参考图，不当作本次生成结果；无图使用空态。

模型读取平台真实目录与能力，不复制原图产品的供应商品牌。角色模板按原图提供“不使用”及九种构图：单特写+三视图、单特写+正面无面部、单特写+三视图无头部、单特写+全身、双特写+正背面无头部、面部三特写+正面无面部、三视图+脸部三特写、三视图+五角度半身照、大头照+全身照。缩略图逐项表达头肩、独立头照、完整全身、颈根以下身体及视角布局。

每次生成一张图片，模板里的特写和视角都位于同一张整图内。“双特写+正背面无头部”为 9:16，上排两张特写、下排两具无头身体；其他内置组合为 16:9。原图“面部三特写+正面无面部”实际由左侧主特写、中间无头身体和右侧三张小脸构成；“大头照+全身照”左侧为不带肩领的独立大头，右侧为无头正面身体。无面部按衣领以下裁切，不画空白脸或打码。场景四宫格同样生成一张包含四视角的整图，独立视图仍通过编辑工作区另行显式生成。

角色模板选择器以真实网格选项呈现，桌面三列、窄屏两列。方向键按所在行列移动，列表自动滚动以完整显示焦点选项；Enter 选择，Escape 取消并回到触发按钮。弹层只有选项列表负责滚动，保留视口边距。

制作期风格修改通过专用 CAS 接口保存，说明实际影响范围，已有媒体保留且不自动重生；已有人工提示词不随作品模板切换被静默覆盖。

## 角色场景与主体资产

作品管理的“主体资产”使用角色、场景、道具分类标签；单集的“角色场景”在“主体管理”右侧紧邻显示上一集、剧集选择和下一集。下方直接呈现角色、场景、道具三栏，保留“编排剧本”入口，移除额外的“补充提取资产”表单、重复分类与全局批选工具栏。新增入口分别位于各栏。

选集切换真实单集路由；已有分镜时按镜头和剧情段的真实主体引用展示，引用造型时带回角色本体。各栏同时提供默认收起的“作品共享 · 本集未引用”区域，保留作品内其他主体的编辑、勾选和生成入口，不将其视为本集引用。已引用角色的未引用造型留在该角色卡“其他造型”内并明确标注。尚无分镜时明确提示展示作品共享主体，不通过名称或描述猜测剧集归属。读取失败或剧集不存在时显示错误，不扩大为全部资产。未保存编辑或操作进行中禁止切集，选择范围按账号、作品和当前集隔离。

每栏有独立总数、全选、逐项勾选和生成图片入口；顶部全选只操作当前引用范围及其已引用造型，保留已单独勾选的共享主体。三栏在桌面独立滚动，窄屏按顺序纵向排列。批量生成使用当前类型已选真实 ID 预检与费用确认，并明确包含手动勾选的作品共享主体；没有道具是正常空态。作品管理仍保留分类内批选。新增允许先保存名称草稿，正式查询返回后自动展开提交时所在集的对应共享区域，刷新后仍可展开找到，不自动改写镜头引用或新增集归属。生成前校验描述、模型、提示词和引用，既有导入与角色库继续沿用真实业务。

### 全屏资产工作区

角色编辑使用全屏工作区，顶部提供返回；左侧设定、声音和生成参数，中央主视觉，右侧版本，底部多视图条。角色定义、外观、声音、模型、画幅、分辨率、提示词与引用使用真实字段，保留已有角色库能力。

每个视图拥有独立名称、提示词、参数、生成结果与版本。主体参考和风格参考分组呈现。角色声音支持现有音色库导入、上传、播放、保存与下载，不能由这些入口推断音色克隆或成片混音。

场景与道具延续设定/参数、主视觉、版本和视图的工作区结构，使用现有多视图、跨作品导入及图片投送。不将这些局部能力描述为完整结构化场景库或道具库服务，也不新增其补齐承诺。

工作区上报 dirty/busy，关闭、返回及切换对象处理未保存修改，保存中冻结退出。该保护针对当前编辑会话，不等同未保存草稿的持久恢复。真实浏览器焦点、滚动和返回行为仍逐项核对。

## 漫剧分镜

### 默认模式

从角色场景进入漫剧分镜时保留“选择分镜生成默认模式”弹窗，四种模式、说明、参数和确认操作位于同一弹窗。确认与原 `assets → story` 阶段操作使用同一次版本校验，仅保存默认设置，不启动收费生成。

| 模式       | 实际设置与行为                                                                       |
| ---------- | ------------------------------------------------------------------------------------ |
| 参考生视频 | 镜数、视频模型、画幅及分辨率；默认参考生视频，使用有效主体参考                       |
| 宫格图     | 保留独立选项；故事板生成、裁片和镜头采用在分镜内执行并分别预检                       |
| 智能导演   | 镜数、视频模型与规格，使用 `smart_drama` 模板；不呈现未接入独立开关                  |
| 故事板     | 图片/视频模型、规格和镜数，使用 `storyboard_detail` 模板；图片与视频仍为真实独立任务 |

后端只写本页拥有的生成模式、导演模板、目标镜数、图片/视频模型、比例、分辨率和视频连续性，保留小说分组及无关设置。比例、分辨率读取实际模型能力。切换默认模式不覆盖已有镜头配置。

未保存镜头配置时，宫格/故事板保持图生视频，使用有效采用图作首帧；参考/智能导演保持参考生视频。缺图、旧图失效或缺少有效参考时要求补图，不能静默降为文生视频。生成任务仍独立预检和确认费用。

### 幕与镜头

左侧为“幕”列表，主体为幕内镜头卡。幕由连续场景分组计算，卡片展示镜头文字、主体引用和媒体状态，保留定位、折叠、局部重拆、新增、状态筛选、素材下载及视频预览。

镜头视频状态筛选与卡片状态颜色只依据视频槽；独立图片的失败、处理中或过期不改变视频就绪状态。

页面“一键生成视频”仍生成所选幕关联的连续剧情段，确认前说明段数、镜数和跨幕整段范围。逐镜视频在镜头工作区生成，不能将关联段批量称作独立逐镜批量。

### 全屏镜头媒体工作区

点击镜头卡直接进入媒体工作区：顶部返回与幕定位，左侧约 25% 的参数区含图片/视频/音频标签，中央约 50% 展示生成与预览，右侧约 25% 为版本，中央底部为当前幕镜头条。首尾帧、主体/本地参考、提示词和运镜保留在所属媒体配置中。

图片、视频、音频各自配置、生成、预览和显式采用，沿用真实 API。切镜、切媒体及离开处理会话修改，资源播放与版本选择保持实际采用关系。推拉摇移、航拍、手持、POV 等预设表达生成意图，实际效果由模型能力决定。

## 视频预览、合成与导出

视频预览保持原稿入口，不增加视频制作或装配阶段。采用、生成任务完成和合成就绪分别表达，不新增逐集人工审批。

- 本集没有任何逐镜视频采用时，沿用完整剧情段时间线；任一镜头存在当前采用指针时，整集按镜头顺序使用全部逐镜视频。
- 缺镜、脚本 hash 过期、采用记录与资源不一致、资源不可用或时长无效均阻断逐镜合成，不混入旧段视频。切换采用版本会使旧成片失效，即使两个版本引用相同资源。
- 就绪结果使用 `renderSource/renderVideoCount/renderReadyVideos/renderBlockingReason` 说明实际来源与阻断原因；旧 `readyVideos` 仍表示段视频数量。
- `story` 阶段的合成任务提交同样校验实际采用的视频来源；完整有效的逐镜视频不要求另行生成段视频。
- 合成携带当前集版本，使用本地 FFmpeg 链路，不隐式生成媒体或要求生成模型预算。旧成片保留，当前输入变化与合成结果分别反馈。

素材包包含所选集已采用的独立镜头图片、视频和音频，以及现有主体、段视频与成片资源。清单的 `image/video/audio` 为实际文件路径；当前脚本 `imagePrompt/videoPrompt` 与采用版本的 `imageTakePrompt/videoTakePrompt/audioText` 分开记录。未采用历史不入包，损坏采用拒绝导出。导出保留用户显式采用素材，不等同当前成片就绪通过。

剪映草稿仍按剧情段视频排列；独立音频不自动混入成片或剪映。独立混音及逐镜剪映没有本轮实现授权，仅在页面说明现有行为边界，不列作本轮 TODO。

## 分集管理

作品管理的分集页保留搜索、顺倒序、状态筛选、多选、新建分集、状态汇总、生成分镜、生成视频、合成与下载操作。打开单集进入“分集剧本”。列表先加载摘要，仅按当前操作范围读取详细数据。

生成按实际范围预检及报价，合成携带单集版本。当前页面逐项显示成功、跳过、阻断、运行、失败或结果不确定，保留本会话已成功结果；已有服务端范围、防重与操作回放继续使用。不承诺刷新或跨登录恢复页面批次记录。

独立“匹配全部主体”批量功能明确排除，现有引用检测、缺图补齐及 `segment_assets` 继续使用，不能将其等同该批量功能，也不为此新增端点或后续补齐任务。

## 通用交互与实现边界

| 主题与可访问性 | 使用既有组件、Lucide 和语义 token；可读选中态、键盘焦点、错误反馈及 reduced-motion 继续逐页核对 |
