# 短剧制作主流程

按用户最新要求收敛主流程，目标是明确“现在在哪、当前做什么、下一步点哪里”。本稿汇总原型约束、已确认决策及实施验收；完整证据与 D4–D22 见[设计决策记录](short-drama-usability-decisions.md)。

## 一条制作主线，两个起点

```text
新作品
上传剧本 → 剧本格式 → 风格设置 → 角色场景 → 漫剧分镜 → 视频预览
             │            │           │          │            │
       创建剧集／单集    全剧默认    编排剧本    按段制作    合成本集 → 下载
          原图设置窗               现有模式选择

已有作品
分集管理 → 打开第 N 集
             ├─ 尚无段／镜头 → 分集剧本
             └─ 已有段／镜头 → 漫剧分镜（沿用阶段限制）

单集五步
分集剧本 → 风格设置 → 角色场景 → 漫剧分镜 → 视频预览
```

原型六步、单集五步的顺序和阶段校验保持。已有作品进入分集管理，用户不必重走新建；打开哪一步按该集是否已有分镜决定，不自动生成。

## 每页负责什么，怎样继续

“主操作”指推进当前制作任务的动作，局部编辑、生成和预览仍放在对应对象旁，不删除已确认保留的工具。

| 页面 | 当前任务 | 主操作与去向 |
| --- | --- | --- |
| 上传剧本 | 提供、确认来源内容 | 沿用现有“下一步：剧本格式” |
| 剧本格式／首次阅读 | 核对正文、制作范围、名称与比例 | 原图“创建剧集／创建单集” → 设置窗口 → 风格；删除重复底部下一步（D4） |
| 分集剧本 | 核对当前集内容 | 沿用单集正常“下一步：风格设置”，不套用首次阅读的删除规则 |
| 风格设置 | 首次设置全剧默认；后续查看默认或设置本集独立风格 | 首次沿用配置确认；后续有改动“保存并继续”，无改动直接继续 → 当前范围主体页（D8–D11） |
| 角色场景 | 核对当前制作范围的角色、场景、道具与参考图 | 首次沿用“编排剧本”及现有模式选择、校验与确认；后续沿用步骤导航进入漫剧分镜 |
| 漫剧分镜 | 选段、检查镜头、生成和处理本段视频 | 按现有阶段完成分镜编排／进入视频预览；段工具与单镜工具各在当前工作区（D12–D13） |
| 视频预览 | 检查本集视频是否就绪并查看成片 | 沿用“合成本集视频” → 播放 → “下载成片”；缺失项继续按现有段／镜头范围处理 |
| 分集管理 | 找到要制作的集 | “打开第 N 集” → 有分镜进分镜，无分镜进剧本（D6） |

风格保存失败或设置阻断时停在当前页：保留输入并定位相关设置。成功后继续，避免让用户保存完再寻找入口；保存、切页与付费生成的边界沿用已确认规则。

“下一步／继续”引导栏固定在工作区底部，正文独立滚动，初次进入长页面即可找到主操作。常规栏高 49px、按钮高 32px，长错误允许换行；队列留在正文，单镜工作区隐藏外层引导栏，避免遮挡和重复操作条。

## 功能只放在所属位置

| 位置 | 负责的功能与边界 |
| --- | --- |
| 作品管理 | 保留剧本设定、风格设置、主体资产、分集管理四页。内部切换保持作品管理范围；“选择分集”统一回分集列表（D5），不恢复旧集位置 |
| 单集风格 | 未独立设置时跟随全剧默认；独立设置只作用于本集。改风格不自动重写已有内容或重新生成（D8–D9） |
| 共用绘图配置 | 绘图模型及角色／场景模板不随单集风格模式锁定，直接可选；明确标注全剧共用，与风格在同次保存中校验并持久化，不改旧产物 |
| 主体工作区 | 文字与图片配置统一“保存修改”；主视觉允许“保存并生成”。底部直接选主视觉或独立视图，参数、预览与版本共同切换（D14–D16） |
| 分镜页 | 集 → 段 → 镜头。左侧段列表，右侧当前段镜头；段工具分制作、调整、视图三组并保持可见。已选段批量操作放筛选下方，底部不重复（D12–D13） |
| 镜头工作区 | 当前单镜的图片、视频、音频配置、生成与采用。场景属于镜头信息，不增加“幕”层级 |
| 更多 → 高级制作台 | 保留分集维护、任务处理、制作设置及现有高级导航；不与主流程争抢常驻入口（D7） |

宫格图、智能导演、故事板继续按已确认的不同模式工作；生成原图是一张图片，不以收敛流程为由合并模式。主体主视觉保留直接生成和按需影响提醒，不新增报价确认（D18）。

## 主流程落实顺序与验收

以下四组已完成本地实现，按对应边界进行代码 review、组件／后端专项及真实页面核对。

1. **先清理入口与落点（D4–D7）。** 首次创建只用原图创建路径；已有作品进分集管理；分集按内容打开；管理出口回分集；高级台入口进更多。验收一次新建、一次打开已有集、一次作品管理往返，不走错层级。
2. **再贯通风格与继续动作（D8–D11）。** 实现真实全剧默认／单集独立保存及继承，随后接入“保存并继续”和阻断设置定位。验收修改本集不影响其他独立集，未独立集跟随默认，保存失败保留输入。
3. **收拢主体工作区（D14–D16）。** 统一文字与图片配置保存，直接选择独立视图，主视觉保存成功后才提交生成。验收不会漏存半组配置，取消确认前不保存、不生成，视图切换不串对象。
4. **收拢段与镜头制作（D12–D13）。** 段工具分组、批量操作移到列表上方；单镜操作留在镜头工作区。验收批量范围与所选段一致，进入预览后可沿用现有合成、播放与下载。

真实页面已核对已有作品直达分集管理、有／无分镜分集落点、管理页继续与选择分集、高级台更多入口、段工具和顶部批量选择。单集风格实际保存、刷新保留后恢复原继承模式；集、段、镜头、媒体与任务记录保持不变。主体工作区检查统一保存、保存并生成文案、非空提示词覆盖取消保稿、关闭放弃、独立视图原位编辑与版本标题。保存失败、双版本冲突、连续视图保存、生成前取消和未知回执由真实组件与后端测试覆盖，不调用付费生成补截图。

桌面与 1024px 分镜明暗主题已检查；段工具同组高度 32px、间距 8px，无整页横向溢出。主体主操作同高 34px；760px 独立视图配置修复画幅与分辨率内禀宽度重叠。验收截图、专项输出及风格保存前后核对记录放在 `.local/cache/short-drama-usability-implementation/`。本地 API 已更新，启动前备份原 SQLite，Schema 116 增量迁移已生效；未提交、推送或部署。

## 当前边界

- 单集独立风格已真实持久化，并接入后续显式分镜撰写、段提示词与重拆。未独立集跟随当前默认，独立集保持自己的设置；共享主体与独立视图继续作品级，不新增集级图片版本。已有完整提示词及媒体配置保留现有优先级，不自动改写或重生成。
- 已确认的提示词覆盖确认、免费后处理 0 积分、队列与版本状态、图片失败说明（D17–D22）保留在决策记录，作为对应模块实施时的约束，不再逐项打断主流程讨论。
- 音视频播放失败、音频等待提示、模板图卡等外围设计暂不展开；本轮完成已确认主流程，不将原完整七维审查标为全部通过。真实付费模型、生成效果与 PostgreSQL 并发仍待目标环境验收。
- 继续排除书单授权、小说服务、转绘、全部主体批量匹配，以及独立混音、逐镜剪映、持久草稿和持久批次恢复。
