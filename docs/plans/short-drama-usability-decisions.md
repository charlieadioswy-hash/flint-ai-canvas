## 已确定的约束

- 新建六步顺序保持：上传剧本 → 剧本格式 → 风格设置 → 角色场景 → 漫剧分镜 → 视频预览。
- 单集五步顺序保持：分集剧本 → 风格设置 → 角色场景 → 漫剧分镜 → 视频预览。
- 作品管理保留剧本设定、风格设置、主体资产、分集管理的职责。
- 保留“集 → 段 → 镜头”，不恢复幕；段级批量、重试和预览，单镜媒体留在镜头工作区。
- 已有分集的作品默认进入分集管理；此前确认的首页紧凑布局、最近作品位置稳定、创意弹窗、主体选集和单张绘图模板作为现状约束。
- 不引入书单与授权、我的小说服务、转绘、全部主体批量匹配，也不扩大到独立混音、逐镜剪映、持久草稿和持久批次恢复。
- 生成只因明确的用户操作启动，已有范围与费用确认合同保持，保存或导航不自动启动付费生成；主体主视觉按 D18 的用户选择保留直接生成，不据此要求它新增报价确认。
