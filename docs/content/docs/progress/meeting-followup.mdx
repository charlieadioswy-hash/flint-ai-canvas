## 来源差异与执行口径

- 原排期把“ControlNet 改接 Inpaint”当作无依赖的小改动；实际需先明确结构控制、控制区域蒙版、图生图重绘蒙版和输出蒙版的合同，当前实现按这几种职责分别处理。
- 原会议和排期写“无实时进度只提示异常”，纪要 T02 的后续评估要求同时显示正常阶段；当前采用无百分比时显示真实阶段的方式。
- 原文“图片铺满”存在完整显示或裁剪的歧义；当前默认适应可视区域，并提供缩放和全屏。
- 原排期中的负责人为建议分配，相关日期是原计划。此清单只更新任务与状态，不重新指定负责人或承诺工期。
