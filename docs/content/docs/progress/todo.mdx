# 待办

本页按专题维护后续演进项；已实现功能的真实验收场景见 [待测试](/docs/progress/pending-test)。

## 图片合规检测

当前范围已实现手动检测、阿里云适配、后台配置及单份报告汇总。以下属于后续扩展，未纳入当前功能：

- 新检测平台适配器：实现 `internal/moderation.Provider`，声明可选地域和服务，完成结果归一化及无外网契约测试后再开放后台类型。
- 批次历史列表和管理员调用统计界面：当前用户读取最新报告或按已知批次 ID 读取，后台未提供完整历史查询和用量报表。

当前产品约定保持手动触发；自动生成后检测、自动补失败项目或跨平台故障切换均不属于当前计划。
